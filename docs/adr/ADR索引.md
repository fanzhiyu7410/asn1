## 状态流转

| 状态 | 含义 |
| --- | --- |
| 提议 | 待项目负责人确认，不得据此实现 |
| 已确认 | 用户已批准，作为实现与评审依据 |
| 已取代 | 被更新 ADR 取代；保留原文，注明替代编号 |
| 已否决 | 明确不采纳；记录原因避免反复讨论 |

## 模板

```markdown
# ADR-XXXX：标题

- 状态：提议 / 已确认 / 已取代 / 已否决
- 日期：YYYY-MM-DD
- 关联：文档链接、相关 ADR

## 背景

要解决的问题、现有约束、失败风险。

## 决策

采用什么，边界是什么。

## 备选方案

至少一个被否决的方案及否决理由。

## 后果

正面影响、代价、需要同步修改的文档/API/测试。
```
